# Artworks Data Storage

This folder contains the artworks metadata in JSON format.

## File Structure

- `artworks.json` - Contains all artwork data (title, description, price, images, etc.)

## Important Notes

- **DO NOT DELETE** this file or the `artworks.json` file
- This data persists across deployments
- Artwork images are stored in `public/artworks/` folder
- Only admins can delete artworks through the admin panel

## Backup

It's recommended to backup this folder regularly, especially before major updates.
